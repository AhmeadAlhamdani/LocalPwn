New black-box assessment

Only assess systems you own or have explicit authorization to test. This version performs discovery and analysis; it does not execute real-world exploitation.

Sent to the localhost server only. Not saved in the SQLite database or browser storage. Cloud requests may incur charges.

Execution safeguards

◈   Scope checked before executing Nmap
◈   No arbitrary LLM-generated shell commands
◈   Local assessment data and evidence
◈   Sensitive API keys excluded from logs
◈   One assessment running at a time
The current worker runs locally but is not yet sandboxed by Docker or a VM. Run LocalPwn inside a dedicated Kali VM. Intrusive exploitation and persistence against external targets are not available in this version.

Local AI

Start Ollama separately and choose Ollama in the assessment form. Default model: gpt-oss:20b. OpenAI and Anthropic keys can be supplied per run or through environment variables.

Operational limitations

Not a general exploitation framework. No remote post-exploitation, persistence, sandbox isolation, persistent job resume, authenticated multiuser dashboard, or streaming terminal. The UI listens on loopback only and should not be exposed via port forwarding.
